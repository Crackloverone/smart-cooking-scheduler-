## 三、迁移前必须确认的三件事

1. **腾讯云控制台防火墙要单独放行 `8137`**（TCP）。只开 Windows 防火墙没用 ——
   症状是"服务器上 `curl 127.0.0.1:8137` 通、外面连不上"。
2. **服务器上要写 `FT_WARM_LLM=off`**（`setup.ps1` 已自动写）。
   否则每次开机白等 60 秒去探测一个根本不存在的本地 Ollama。
3. **AI 对话走远程档**：在网页「设置 → 模型接入」里选「远程」，填
   `https://potatoya.cn/pro100x/v1` + 模型名 + API Key。详见教程「附 A」。

## 四、两个会卡住部署的坑（实测踩到过）

### 坑 1：`pip` 报 `(from versions: none)` —— 是"源被挡"，不是"包不存在"

- 现场：`pip.ini` 里配着清华源时，`curl` 打开镜像页返回 **200**、
  Python 的 `urllib` 也返回 **200（169KB）**，**只有 pip 一个版本都找不到**
  （连 `Collecting` 都不打印）。
- 处理：换源重装，官方源实测**立刻装上**：

  ```powershell
  cd C:\cooking-agent
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt `
    -i https://pypi.org/simple/ --trusted-host pypi.org
  ```

- **不要花时间怀疑包名或 Python 版本。**

### 坑 2：中转站会限流（`429`）→ 触发 30 分钟熔断

- 现象：短时间**连发请求**会被中转站拒（`429`）。项目对 `429` 的处理是
  `_trip("quota")` → 冷却 `FT_LLM_CB_QUOTA`（默认 **1800 秒**），期间 AI 对话
  一直提示"已切换为离线模式"。
- 影响面：**正常聊天（几秒一句）不会触发**；刚配好就猛点「测试连接」会撞上。
- 恢复：等 30 分钟，或在「设置」里重新保存一次模型配置（会复位熔断器）。
- 另外单次调用超时是 **20 秒**，偶发卡顿时会等满 20 秒才回离线文案；
  想放宽可在 `.env.local` 加 `FT_LLM_TIMEOUT=45`，然后重跑 `setup.ps1`。
- 补充：填 `gpt-5.6-sol`，中转站**实际路由到 `step-3.7-flash`** 并在响应里如实回报，
  这是正常的 —— 只要**有回复**就说明链路通了。

> ⚠ **排查"远端偶发超时"之前，先看一眼有没有代理**（`env | grep -i proxy`）。
> 本次验收中，开发机的沙箱代理把中转站的 `429` 伪装成了"精确卡满 20 秒"，
> 一度让人误判成"中转站不可靠"。服务器上没有这个代理，不受影响。

## 五、怎么自己再验一遍

**开发机**（打新包并自查）：

```powershell
cd D:\Xuzj\ky\Project\ft
.\deploy\windows\pack.ps1          # 产出 dist\cooking-agent-windows.zip，自带复核
```

**服务器**（部署后 6 项冒烟）：

```powershell
# 从 .env.local 里取出令牌
$t = ((Get-Content C:\cooking-agent\.env.local -Encoding UTF8 |
        Where-Object { $_ -like 'FT_AUTH_TOKEN=*' }) -split '=', 2)[1]
Invoke-RestMethod http://127.0.0.1:8137/health                      # {"status":"ok"}
Invoke-RestMethod http://127.0.0.1:8137/ready                       # {"ready":true,"recipes":100}
$h = @{ 'X-Auth-Token' = $t }
$b = '[{"id":1,"name":"家常鲈鱼"},{"id":2,"name":"豉汁蒸草鱼"}]'
(Invoke-RestMethod http://127.0.0.1:8137/api/plan -Method Post -Headers $h `
   -ContentType 'application/json' -Body $b).overview.recipeCount   # 应为 2
```

浏览器打开 `http://111.230.129.109:8137/app?token=你的令牌`，右下角「AI 对话」
发一句"你好"，能收到回复即达标。
